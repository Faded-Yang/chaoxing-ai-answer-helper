# reference —— 上游基线快照

这个目录只放**上游脚本的原始快照**，用于对照本 fork「改了什么 / 还缺什么」。

| 文件 | 说明 |
| --- | --- |
| `upstream-0.2.3.user.js` | 本 fork 的基线：上游「超星学习通｜知到智慧树--网课小助手」0.2.3 原样副本 |

## 为什么留这个

1. **可验证**：README 里说「我们缺 0.2.8 的 `watchVideoQuiz` 等 4 项」，可以直接和上游源码对照确认。
2. **可复现 diff**：想自己看改了什么，用任意 diff 工具比较它和根目录的
   `chaoxing-zhihuishu-ai.user.js` 即可；AI 改造集中在文件前半部分（`AI_*` 常量与 `getAnswerFromAi` 一带）。
