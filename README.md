## 2. 为什么改这些：一次实测的归因

一份文科小测（28 题 / 满分 100）实得 **73.5**，逐题归因如下：

| 题型 | 题数 / 分值 | 得分 | 失分原因 |
| --- | --- | --- | --- |
| 单选 | 15 / 45 | 36 | 3 题错在「通识上更顺口、但不是本讲口径」的干扰项 |
| 多选 | 8 / 40 | 22.5 | **最大失分源**：2 题「全选」判 0 分、3 题漏选只拿半分 |
| 判断 | 5 / 15 | 15 | 全对（通道正常） |

三条结论直接变成了上面的改动：

1. **多选题不是「会不会」，是策略错。** 漏选按比例给分、错选整题 0 分，而原来的提示词写的是
   「请给出全部正确选项」——正好把人往最亏的方向推。
2. **文科题的干扰项来自讲义口径。** 题干和选项措辞基本照抄课件，模型只有知道「这一讲讲什么」
   才能选对；把作业标题当上下文传过去，成本几乎为零。
3. **判断题/填空通道本身没问题**，不需要动。

> 说明：仓库里不含任何真实题目、答案或课程内容，只保留上述统计。

## 3. 安装

1. 装一个用户脚本管理器：[ScriptCat（脚本猫）](https://scriptcat.org/) 或 Tampermonkey
2. 点上面的 **raw 安装链接**（本 fork 版本号故意写成 `9.9.9` 且不声明 `@updateURL`，
   避免脚本管理器用上游新版覆盖掉 AI 改动；**请在该脚本的「检查更新」里关闭自动更新**）
3. 打开「答题」标签页，填自己的 API Key
4. 点「拉取模型」选一个模型
5. 进作业/考试/章节页 → 面板出现后**点「开始」**

## 4. 联网搜索怎么配

| 服务 | 需要填 | 说明 |
| --- | --- | --- |
| **Tavily**（推荐） | Key（`tvly-` 开头） | AI 专用搜索，返回结果最干净，官网有免费额度 |
| **Bing** | Azure 的 Bing Search v7 订阅密钥 | 质量稳定，需要 Azure 账号 |
| **SearXNG** | 实例根地址（如 `https://searx.be`） | 免费/可自建，但**该实例必须允许 JSON 输出** |
| **自定义** | 完整 URL 模板，用 `{q}` 表示关键词 | 返回带 `results`/`items`/`data` 的 JSON 即可接 |

**触发时机**（默认「选择/判断先搜」）：

- `选择/判断先搜` —— 单选、多选、判断题都先搜再答（文科最有效，每题多一次搜索 + 略多 token）
- `AI 没答出来才搜` —— 只在 AI 解析失败时兜底，最省
- `所有题都先搜` —— 包括填空/简答

搜索失败、没填 key、实例不通时**静默跳过**，绝不因为搜索问题卡住答题。

## 5. 隐私与边界

- **API Key 只存在你本机的脚本存储里**，只由脚本自己发往你填的接口地址；本仓库不含任何密钥。
- 发出去的只有：题干、选项、题型，加上**本页的作业/章节标题**（作为口径上下文），
  开启联网搜索时再加搜索到的公开资料摘要。
- 不上传任何数据到第三方服务器，不做代理中转，没有统计上报。
- 联网搜索需要 `@connect *`（上游 header 里已有），自定义端点才能用；不信任可只填官方域名。

## 6. 已知限制

- **AI 会答错**，尤其是细节题和「哪个表述最贴合本讲」这类题；把作业标题当上下文能改善但治不了根。
- 当前**不支持视频弹题**（见 1.2），视频卡在弹题时请手动作答或等上游合并。
- 智慧树只支持答题（与上游一致）。
- 题目被页面锁定后需要点「修改/重做」才能重写（面板「重写答案」按钮有提示）。
